TVI Network Design

Three sites, 11 nodes: the smallest topology that still shows every one of the 10 assignment steps. Draft for the group to review.

Topology

Solid grey lines are physical links. Dashed purple lines are IPsec tunnels that ride over the ISP links. Endpoints on each access switch (staff PCs, servers, phones, IoT) are VLANs, not extra nodes.

Build order

  1. All 11 nodes cabled, console access works, hostnames and management IPs set.
  2. VLANs, trunks, LACP, STP at HCM, then HN and DN.
  3. HSRP and DHCP: a PC in each VLAN gets an address from the server.
  4. OSPF inside each site, then BGP to the ISP, then the IPsec tunnels.
  5. NAT and ACL, then Snooping and DAI, then QoS.
  6. Netmiko script pushes all of the above; rebuild from blank configs to prove it.
  7. Failover drill: pull a core link, time the recovery, target under 3 minutes.

Open choices

  1. Platform for the real lab: EVE-NG or GNS3 on a teammate's x86 PC. Needs the team's RAM and CPU numbers.
  2. Image source for Cisco devices. Needs an answer from the lecturer.
